# Add your music

Put your own `.mp3`, `.ogg`, or `.wav` files in this folder. Then add each file to `tracks.json`:

```json
[
  { "title": "The Enchanted Dungeon", "file": "enchanted-dungeon.mp3" },
  { "title": "Boss Battle", "file": "boss-battle.ogg" }
]
```

The browser only starts playback after the player presses the play button.
